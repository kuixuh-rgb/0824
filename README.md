# 旅日好天氣 Travel Weather

這是一個可以直接部署到 Cloudflare Pages / GitHub Pages / Netlify 的純前端旅遊天氣網站。

## 功能
- 台灣 22 縣市選擇
- 瀏覽器目前位置定位
- Open‑Meteo 即時天氣與 7 日預報
- 降雨機率、濕度、風速、UV、體感溫度
- 根據天氣產生旅行提醒
- OpenStreetMap / Overpass 搜尋附近景點、美食與飲料
- 搜尋距離 2 / 5 / 10 / 20 km
- 顯示 OSM 提供的營業時間
- 自動產生一日行程
- 深色模式
- 手機 / 平板 / 電腦 RWD

## 檔案
- index.html
- styles.css
- app.js

## Cloudflare Pages 部署
1. 將三個檔案放在同一資料夾。
2. 上傳到 GitHub 儲存庫。
3. Cloudflare Pages → Create a project → Connect to Git。
4. Framework preset 選 None。
5. Build command 留空。
6. Build output directory 填 `/` 或依 Cloudflare UI 使用根目錄設定。
7. Deploy。

如果你原本已經是 Cloudflare Pages 專案，直接以這三個檔案覆蓋舊版即可。

## 注意
- Open‑Meteo 不需要 API Key。
- Overpass / OpenStreetMap 不需要 API Key，但屬公共服務，偶爾可能忙碌或限流；程式已放入第二個備援 endpoint。
- OpenStreetMap 並不是每一間店都有完整營業時間，因此缺少資料時會提示使用者查看店家官方資訊。
- 日期查詢目前設為今天至未來 6 天，符合 Open‑Meteo 7 日預報範圍。
